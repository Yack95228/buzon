Política de privacidad de Buzón

Última actualización: 20 de noviembre de 2026

Quién la usa

Buzón es una aplicación de escritorio para macOS que usa una sola persona, su autor, para leer su propia cuenta de Gmail. No se ofrece al público.

Qué datos usa

Con el permiso de solo lectura de Gmail (gmail.readonly), Buzón descarga los correos, las etiquetas y el historial de cambios de la cuenta de su usuario.

Dónde se guardan

Los correos se guardan solo en el propio Mac del usuario. Las credenciales de acceso (tokens de OAuth) se guardan en el Llavero de macOS. Buzón no tiene servidores propios.

Con quién se comparten

Con nadie. Buzón no envía el contenido del correo a terceros, no usa publicidad, analítica ni seguimiento, y no vende ni transfiere datos. El uso de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.

Cómo borrarlos

Desde Ajustes → Cuenta → «Desconectar», Buzón borra la copia local y el acceso guardado en el Llavero. El acceso también se puede retirar en cualquier momento en myaccount.google.com/permissions.

Buzón is a single-user desktop app. With read-only Gmail access it stores the owner's mail only on the owner's Mac and OAuth tokens in the macOS Keychain. Nothing is shared with third parties; use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements.
